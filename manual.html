Headroom — Manual

A light mixing & recording console that runs in your browser. This page covers getting it running, connecting an interface like an XR18, using the console, and fixing the most common problems.

Requirements

Headroom needs to be opened over http:// or https:// — a hosted link, or a local server on localhost. Opening the file directly by double-clicking it (file://) will not work; browsers block the audio engine in that case.

Chrome or Edge give you the full feature set, including switching the output device from inside the app. Firefox and Safari work fine for input, mixing, and recording, but output-device switching isn't supported in those browsers yet — use your operating system's sound settings to pick the output device instead.

You'll be asked to grant microphone/audio permission when you power on — this is required even if you're using a dedicated interface rather than a microphone, since that's the same permission browsers use for all audio input.

Getting started

  1. Open the hosted link.
  2. Tap the Power on button.
  3. Grant audio permission when your browser prompts you.
  4. You'll land on the console with one track already set up, ready to assign an input.

Connecting your interface

Use the Interface selector in the top bar to choose your audio device — this could be a Behringer XR18, another USB interface, or your built-in mic.

Once an interface is selected, every track's channel dropdown lists the individual channels available on that device. Pick whichever channel a track should listen to — several tracks can each listen to a different channel of the same interface at the same time.

If a multichannel interface like the XR18 only shows 2 channels, the browser is only seeing what your operating system has negotiated with the device. Check your OS's sound settings for that device (on Windows: Sound Control Panel → the device's Properties → Advanced) and set it to its full multichannel format.

If you plug in a device after the app is already open, the interface list refreshes on its own — just open the dropdown again.

Track controls

Name
Tap the track name at the top of the strip to rename it.
Trim
Input gain, ±20dB. Drag the knob up or down, scroll to nudge, double-tap to reset to 0.
Pan
Left/right position in the mix.
EQ — Low / Mid / High
Fixed-frequency shelf/bell EQ, ±15dB each band.
Fader
Main level. Drag to adjust, double-tap to snap back to unity (0dB).
Meter & clip light
The bar shows signal level; the small light above it flashes if the signal is clipping — pull the trim or fader down if it does.
Mute / Solo / Arm
Arm (shown in red) marks a track to be included the next time you record.

Master section

The strip on the far right is the master bus — its fader controls overall output level, and its meter shows what's actually being sent out. A limiter is always active on the master bus with its ceiling set at −1dB, to catch unexpected overs.

The Out selector in the top bar picks your output device, on browsers that support it (see Requirements).

Recording & exporting

  1. Arm at least one track.
  2. Tap Record. Every armed track starts recording, along with a master reference mix.
  3. Tap Stop when you're done.
  4. The Recordings panel opens with a download link for each file — one WAV per armed track, plus a "Master mix" file.

Per-track recordings capture the signal after EQ and pan but before the fader — so riding a fader during a take doesn't get baked into the file. The master mix recording captures the actual output, after the limiter.

Troubleshooting

"Unable to load a worklet's module" / power-on fails

The page was opened as a local file. Open it via a hosted link or http://localhost instead — see Requirements.

No sound, meters aren't moving

Check that the Interface dropdown has your device selected, and that the track's own channel dropdown isn't set to "No input."

A multichannel interface only shows 2 channels

This is an operating-system setting, not an app setting — see the note under Connecting your interface.

Output device dropdown is greyed out

Only Chrome and Edge currently support switching the output device from inside a web page. On other browsers, change the output device through your operating system's sound settings instead.

Distorted or crackling sound

Watch for the clip light above each meter. If it's flashing, pull that track's trim or fader down a little, and check the master meter isn't clipping too.

If none of the above fixes it, it may be a browser or device quirk worth a bug report rather than a setup issue — note what browser and device you're on.
